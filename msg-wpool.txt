## w-brain-drive.js：问题传不全（用户报「传都传不明白，就传不全」）
- 根因: :355 `const [,, cmd, a1, a2] = process.argv` 只取固定位置
    askall "完整问题"      → argv[3] 完整 ✔
    askall 完整问题 有空格  → argv[3] 只剩前半截，argv[4] 被丢弃 ★
    含换行的代码块          → 只剩第一行 ★
  再叠加 PS 单双引号/反引号/$ 的传参展开（AGENTS.md 第6条已记的那两条坑）
- 修法（向后兼容，老用法不变）:
    ① 新增 --file <路径>：问题从文件读，绕开一切 shell 引号规则
       node w-brain-drive.js askall --file q.txt
       node w-brain-drive.js ask deepseek --file q.txt
    ② ask <平台> <问题…>  问题 = argv[3..] 用空格全拼
    ③ askall <问题…>       问题 = argv[3..] 用空格全拼
- 实测: --file 送 3 行含反引号/单双引号/表格管道符 → meta.q 92 字全达；
        不加引号的空格句 → 26 字全达（原来只剩 4 字「一句话回答」）
- 踩坑: 我第一版把 --file 的位置参数顺序搞反（设计成 `ask --file q.txt glm`，
  实际调用是 `ask deepseek --file q.txt`）→ meta.q 为 0 字；
  另外我一开始读 $j.q 判空，其实 q 在 $j.meta.q 里，**是我的校验写错不是代码错**
