## ★ 「为什么一直显示 1/5」—— 这是对的，不是 bug

用户问的第二个问题，答案：

```
轮次(round) 只在【阶段绕回开头】时才 +1
  ①计划 → ②编码 → ③验证 → ④收口 →（next）→ ①计划 = 第 2 轮
```

实测当前状态：
```
active = 20260930-005946-冻结第二批架构边界v2
stage  = verify   （第 3/4 阶段）
round  = 1/5      wrap = 0
```

**没有一个任务走到过 `close` 阶段再 `next`**，所以 `wrap` 全是 0，round 自然全是 1。
不是没更新，是**还没绕完一圈**。

想看它动起来：当前任务已经到 `verify`（3/4）了，再走两步：
```
stager put --kind evidence      （补验证证据）
stager next                    （→ ④ 记录收口）
stager next                    （→ 绕回 ①，轮次变 2/5，marks 清空）
```

**桌宠的 1/5 和这里的 1/5 是同一个数**，它 1.2 秒轮询一次，状态一变就换表情 + 换数字。
