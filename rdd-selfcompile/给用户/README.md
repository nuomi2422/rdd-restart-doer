# 给用户 · 你要看的东西都在这

> **凡是"给你看的"或"你要用的"，一律放这个文件夹。**
> 不放 `mutations\`、不放 `report\`、不放临时目录 —— 你不该为了找一个报告去翻 61 个变异目录。

## 分区

| 文件夹 | 放什么 | 例子 |
|---|---|---|
| `报告\` | 这轮/这次做完的总结报告 | 整顿报告、验证报告、对比报告 |
| `工具\` | **给你用的**工具（双击就能跑的那种） | 一键体检脚本、导出工具、看图工具 |
| `截图\` | 验证过程的画面证据 | 桌宠渲染、MC 验证截图、门禁输出 |
| `文档\` | 给你的说明文档（不是给我自己看的技术规格） | 上手指南、这次改了什么（人话版） |

## ⚠️ 和其它目录的区别（别搞混）

| 目录 | 谁用 |
|---|---|
| **本目录 `给用户\`** | **你** —— 要看、要用、要点的 |
| `scripts\` | 我 —— 闭环真源，别乱动 |
| `scripts\verify-tools\` | 我 —— 我自己写的验证工具 |
| `mutations\` | 我 —— 每次变异的临时工作区（61 个目录，**不要你去翻**） |
| `report\` | 我 —— 外脑审稿原文 |
| `.stager\`（stager 项目） | 我 —— 阶段状态机 |

## 怎么用

**AI 放东西进来时应该**：用 `stager publish`（会自动登记到 `INDEX.md`），不要手写。

```powershell
node "D:\rdd\workspace\stager\bin\stager.js" publish "<文件>" --as report|tool|shot|doc --title "<标题>"
```

## 索引

见本目录下的 `INDEX.md`（每次 publish 自动更新，最新的在最上面）。
