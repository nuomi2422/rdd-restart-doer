## 三、★ 检索没能帮上忙的地方（诚实记）

1. **`find_tools` 的展开成本** —— 库里没有任何关于「展开一次要多少 token / 模型多爱展开」的记录。
   **根因**：`find_tools` 从来没被记进 `tools.jsonl`（一天 12,250 次 `tool_call` 里一次都没有）。
   ⇒ **库里的空白 = 埋点的空白。** 下一步该补埋点，不是补文档。
2. **「AI 不动」是停摆还是收工** —— 库里没有这条判据。本轮我差点误判（10 分钟静默看着像卡死），
   是用户点出来的。**已补进 `坑-StallWatcher不看向标达成只看向工具调用`。**
3. **成本占比** —— 库里没有 token 构成的基线，本轮第一次量（`8,611` 中位，input:output = 8.9:1）。
